WHEN TO USE THIS

The code works, but the product still feels provisional.

  • Flow debt. Screens exist, but the user journey follows implementation history instead of user intent.
  • State debt. Loading, error, empty, permission and recovery states are incomplete.
  • System drift. Generated UI introduces duplicate components, spacing and interaction rules.
  • AI trust gaps. Users cannot tell what the system is doing, what changed or how to recover.
